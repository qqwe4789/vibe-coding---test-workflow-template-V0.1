# Architecture Decision Records (ADR)

记录项目中重要的架构与流程决策，供 Copilot 和团队成员查阅。

## 什么时候写 ADR

- 引入新技术栈或框架
- 选择了非显而易见的实现方案
- 修改了核心流程或约束规则
- 踩过坑并确定了应对方式

## 如何写

1. 复制 `000-template.md`，按序号命名（如 `002-xxx.md`）。
2. 填写状态、背景、决策、后果。
3. 通过 PR 合并，关联对应 Issue。
