# Prompt Library

本目录用于复用 Copilot 的流程化提示词。

## Files

- `plan-task.prompt.md`：任务拆解与执行计划。
- `implement-task.prompt.md`：实现与验证过程。
- `review-task.prompt.md`：PR 评审清单。
- `retro.prompt.md`：周复盘与改进建议。

## Usage

1. 从对应模板复制到 Copilot Chat。
2. 按模板填入 Issue/PR 上下文。
3. 输出结果后，按仓库工作流执行。

## Rule

- 模板应保持“最小改动、可验证、可回滚”一致原则。
